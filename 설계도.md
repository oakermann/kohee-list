# Kohee List blueprint
<!-- parts: functions/api/*.js server/*.js site/*.html site/assets/*.js site/assets/*.css schema.sql scripts/*.mjs wrangler.toml -->
Cafe curation site https://kohee.pages.dev — no accounts ('my reports' via a random browser token), the admin publishes. Source context = `docs/KOHEE_MASTER_CONTEXT.md`.

## Big picture

```
 browser
   site/index.html(list·near me·search·cafe sheet) · submit.html(reports·error reports) · mypage.html(saved·my reports) · admin.html(ops)
   site/assets/*.js ── common.js(api·saved·client token·Naver Map)
   │ /api/*
 ┌─▼──── Cloudflare Pages function functions/api/[[path]].js → server/app.js ──────────────┐
 │ routes.js route table → cafes.js(cafes·reports·notice) · errorReports.js · csv.js · admin.js(lock) │
 │ shared.js(JSON·cookies·text tidying)                                                     │
 └──────┬─────────────────────────────────────────────────────────────────────────────────┘
        │ D1(schema.sql, migrations/ by hand only)
```

## 1. Server

### functions/api/[[path]].js
Pages function entry — every /api/* to server/app.js.
- function `onRequest` — hand off to handle

### server/app.js
- function `handle` — find the route, errors as JSON

### server/routes.js
Route table (source of truth). Admin routes locked by adminOnly.
- route `/data` — all public cafes (for the screen)
- route `/cafes` — admin cafe list (with memos)
- route `/notice` — read/write the notice
- route `/submit` — cafe report (visitors)
- route `/my-submits` — my reports (client token)
- route `/error-report` — error report (visitors)
- route `/my-error-reports` — my error reports and answers
- route `/error-reports` — error report list (admin)
- route `/reply-error-report` — answer an error report (admin)
- route `/resolve-error-report` — close an error report (admin)
- route `/add` — add a cafe (admin)
- route `/edit` — edit a cafe (admin)
- route `/publish` — publish a report (admin)
- route `/delete` — discard/unpublish (admin)
- route `/restore` — restore (admin)
- route `/purge` — delete for good (removed only, admin)
- route `/geocode` — address → coordinates (admin)
- route `/import-csv` — insert CSV (admin)
- route `/admin/login` — admin login
- route `/admin/logout` — log out
- route `/admin/me` — logged in?

Insert cafes by CSV (all as candidates).

### schema.sql
Full D1 schema — three tables: cafes (reports, candidates, public, removed all in one), error_reports, settings (notice etc.). Changes go in migrations/ by hand.
